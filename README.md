# C++ Circuit Simulation Engine and SDL Interface

Two implementation phases develop a SPICE-inspired C++ circuit simulator with polymorphic elements, numerical circuit analysis, command processing, and an SDL graphical interface. No separate phase-1/phase-2 narrative report is included, so this English report is reconstructed from the supplied source and assignments.

## Technical highlights

- Co-developed a C++ circuit simulator with polymorphic element models, modified nodal-analysis routines, and command-based circuit editing.
- Extended the simulator with an SDL interface for circuit interaction and simulation-result plotting.

# C++ Circuit Simulation Engine and SDL Interface

Two implementation phases develop a SPICE-inspired C++ circuit simulator with polymorphic elements, numerical circuit analysis, command processing, and an SDL graphical interface. No separate phase-1/phase-2 narrative report is included, so this English report is reconstructed from the supplied source and assignments.

Virtual element operations permit common circuit handling across component types.

## Circuit representation and numerical analysis

Circuit stores nodes, elements, and analysis requests. The source assembles real/complex linear systems and uses elimination/back substitution routines. Modified nodal analysis introduces extra unknowns for voltage-source/inductor relations and stamps component equations into a shared matrix. A resistor between two non-ground nodes contributes conductance to both diagonals and its negative to the off-diagonal pair. DC, AC, and transient paths require different component models. Capacitor and inductor transient equivalents depend on timestep and prior state; AC uses frequency-dependent impedances. Nonlinear diode analysis needs an explicitly defined linearization and convergence test. Merely including a Diode class does not establish accurate nonlinear simulation under every bias condition. Pivoting, tolerances, singular-node detection, and clear error reporting are essential. Floating subcircuits, incompatible ideal-source constraints, and poorly conditioned matrices should be rejected or diagnosed. Results must also preserve requested variable order and units. The analysis routines are present; agreement with a reference SPICE suite has not been established by these demonstrations.

## SDL interface and build

CircuitRenderer creates a resizable SDL window and accelerated renderer, handles events/text input, draws components and labels, and renders simulation plots. Plot areas use clipping and color-coded series; cursor-related code supports examining plotted results. SDL_ttf handles font rendering. Browser-specific code is guarded by __EMSCRIPTEN__, so a native build should not need Emscripten headers merely because they appear in that conditional block. The phase-2 CMake file selects C++20 and links MinGW/SDL2 libraries including SDL2main, SDL2_image, SDL2_ttf, and SDL2_mixer. Reproduction requires compatible development libraries and runtime assets; the source alone does not imply that every host already has them installed. Hardcoded linker flags should be replaced with discovered/imported CMake targets for portability.

## Detailed element responsibilities and matrix construction

Element is the polymorphic base for component identity, terminals, and component behavior. Resistor contributes conductance; capacitor/inductor need time-step state for transient analysis and frequency-dependent behavior for AC analysis. Independent voltage sources add branch-current unknowns and voltage constraints, while independent current sources contribute to the right-hand side. VCVS/VCCS models use controlling voltages; CCVS/CCCS need a defined controlling branch current. A diode requires nonlinear evaluation and linearization under a specified model. Merely creating the class is distinct from demonstrating converged accuracy. Node identifies electrical connectivity; ground removes one otherwise redundant reference degree of freedom. Circuit holds the components and requests, Simulator executes analysis, and CircuitRenderer maps the model/results to the SDL display. Phase 2 adds structured requested output variables and plottable expressions. Parsing, solver state, and display should agree on names, node signs, and units. Unknown components or malformed values require errors rather than silent defaults. For a resistor joining nodes a/b, G_aa and G_bb increase by 1/R and G_ab/G_ba decrease by 1/R where both nodes are non-ground. A voltage-source branch introduces incidence entries connecting its branch-current unknown to node KCL and a source-voltage constraint. Capacitor current is C*dv/dt; inductor voltage is L*di/dt. The chosen discretization determines their companion stamps and history terms. AC uses j*omega rather than a transient timestep. These equations explain the submitted MNA responsibilities without claiming reference-SPICE agreement.

## Detailed command and interface responsibilities

The first phase covers textual construction and analysis. The second phase adds SDL event handling, component drawing, text input, and waveform visualization. Output-variable requests must preserve whether they refer to a node voltage, branch current, or expression. Plot axes need consistent physical units and time/frequency domains. Clipping prevents plotted lines from drawing outside the plot area, and distinct colors help compare traces. Fonts/images are runtime assets rather than numerical source files. The assignment includes optional serialization and network features, but the inspected implementation does not establish that they are complete.

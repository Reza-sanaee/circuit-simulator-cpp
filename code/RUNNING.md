# Execution and reproduction guide

## Environment

C++20 compiler. Phase 1 is the command-line implementation; phase 2 needs SDL2, SDL2_image, SDL2_ttf, and SDL2_mixer plus its font/assets. The original CMakeLists uses MinGW-style flags and may require local portability edits.
